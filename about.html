About this place

关于这块自留地

fly free · write true

这里是 freebird 的自留地。名字里的「自由」不是口号，而是一种工作方式：想法来了就写，写完就发布，不把表达困在草稿箱里。

「鸟」提醒我保持轻盈——轻装、轻信、轻快地穿过信息噪声。站点用 GitHub Pages 托管静态页面，用一个独立的 Node 服务承载文章、留言与后台管理。

如果这里有哪句话让你想起自己的天空，欢迎写信给我。

技术栈

静态前端：原生 HTML / CSS / JavaScript，零构建，直接由 GitHub Pages 托管。
后端：Node.js 内置 HTTP 与 SQLite，零第三方依赖，提供文章、评论、统计与后台 API。
动效：飞鸟、羽毛轨迹、极光与风流、视差与页面转场，并且尊重系统的「减少动态效果」设置。
